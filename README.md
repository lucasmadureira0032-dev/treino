# Guia de Treino

App pessoal de treino, dieta, água e suplementos. HTML único, funciona offline e
sincroniza na nuvem (Supabase) com login.

- **App:** `index.html`
- **Instalável (PWA):** `manifest.webmanifest`, `icon.svg`, `sw.js`
- Conteúdo pessoal (dieta e regras) fica no banco privado, atrás do login — não no código.
